03 / Coverage and interpretation

All search-data URLs have a supplied HTML snapshot.

  • HTML snapshots only: no HTTP status, robots.txt, JavaScript rendering, Core Web Vitals, backlink or competitor validation.
  • Inbound counts refer only to supplied snapshots. Unverified targets are not confirmed broken links.
  • Character ranges and heading checks prompt editorial review; they are not ranking rules.
  • CTR is total clicks ÷ total impressions. Position is weighted by impressions; query/page totals may differ from Search Console property totals.
  • Correctness and completeness of user-supplied data remain the analyst's responsibility.

04 / Suggested work sequence

  1. Confirm noindex and canonical intent with the SEO owner.
  2. Repair missing or duplicated metadata and clarify program page headings.
  3. Review top query/page pairs for search intent, program detail and internal-link opportunities.
  4. Record each change and compare equivalent post-change periods in Search Console; account for seasonality and other changes.
